TÍTULO:
Backup y recuperación con SQLite | Demo + GitHub Actions

DESCRIPCIÓN:
Demostración educativa en español sobre estrategias de backup de bases de datos, sin Microsoft SQL Server.

El video muestra la construcción del laboratorio, una copia completa SQLite, cambios posteriores, pérdida simulada y recuperación verificada. Incluye SHA-256, integrity_check, comparación de registros y despliegue automático mediante GitHub Actions.

Es un montaje de capturas reales y textos explicativos en pantalla, sin narración ni cámara. Todos los datos son ficticios. SQLite se ejecuta en el navegador; GitHub Pages aloja la aplicación estática. No es un servicio de backups de producción y no implementa backups incrementales, diferenciales, PITR ni retención remota.
